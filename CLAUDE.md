## Critical Conventions

### File Structure

```
src/docscraper/        # Library package
├── core/              # Scraping + processing engines
├── cleaning/          # Content cleaning + AI classification
├── optimization/      # Chunking
├── gui/               # Tkinter interfaces
├── cli/               # CLI entry points
└── utils/             # Shared utilities
api/                   # FastAPI application (Phase 1+)
tests/                 # Test files
scripts/               # Utility scripts
```

### Python Standards

- **pathlib over os.path** — Always use `Path`
- **Type hints on all public methods** — PEP 484
- **Google-style docstrings** — For all public classes/functions
- **`logging.getLogger(__name__)`** — Never `logging.basicConfig()` in library code
- **Specific exceptions** — Never bare `except:`
- **async/await for I/O** — Match existing engine patterns

### Naming

- Modules: `snake_case.py`
- Classes: `PascalCase`
- Functions/methods: `snake_case`
- Constants: `UPPER_SNAKE_CASE`
- Test files: `test_*.py`
