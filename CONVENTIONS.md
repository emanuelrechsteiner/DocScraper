### Rules

- **Core engines** live in `src/docscraper/core/` — never add API or web logic here
- **API layer** lives in `api/` — separate from the package to maintain library usability
- **Tests** live in `tests/` — test files mirror the package structure
- **Scripts** live in `scripts/` — standalone runnable utilities, not importable modules
- **GUI files** live in `src/docscraper/gui/` — Tkinter interfaces

### Correct vs Incorrect

```python
# CORRECT: Import from package
from docscraper.core.scraper import DocumentationScraper
from docscraper.cleaning.cleaner import PostScraperCleaner

# INCORRECT: Import from file path
from DocScraper import DocumentationScraper  # Old root-level import
```

| Category | Convention | Example |
|----------|-----------|---------|
| Python modules | snake_case | `post_processor.py` |
| Python classes | PascalCase | `class DocumentationScraper` |
| Test files | test_ prefix | `test_core_components.py` |
| Scripts | snake_case, descriptive | `resume_processing.py` |

| Documentation | UPPER_CASE.md (Torvaldsen) | `BRAINSTORM.md`, `ARCHITECTURE.md` |

## Python Patterns

### Import Order

```python
# 1. Standard library
import asyncio
import logging
from pathlib import Path
from typing import Optional

# 2. Third-party packages
from fastapi import FastAPI, Depends
from pydantic import BaseModel
from crawl4ai import AsyncWebCrawler

# 3. Internal package imports
from docscraper.core.scraper import DocumentationScraper
from docscraper.cleaning.rules import CLEANING_PATTERNS

# 4. Relative imports (within same package)
from .utils import sanitize_url
```

### Class Structure

```python
class DocumentProcessor:
    """Process documentation files for vector database ingestion.

    Args:
        input_dir: Directory containing raw markdown files.
        output_dir: Directory for processed output.
        use_llm: Whether to use LLM for classification.
    """

    def __init__(
        self,
        input_dir: Path,
        output_dir: Path,
        use_llm: bool = False,
    ) -> None:
        self.input_dir = input_dir
        self.output_dir = output_dir
        self.use_llm = use_llm
        self._logger = logging.getLogger(__name__)

    async def process(self) -> ProcessingResult:
        """Process all documents in input_dir."""
        ...
```

### Key Rules

- **pathlib over os.path** — Always use `Path` for file operations
- **Type hints on all public methods** — Use PEP 484 syntax
- **Google-style docstrings** — For all public classes and functions
- **Logging via `logging.getLogger(__name__)`** — Never `logging.basicConfig()` in library code
- **Specific exceptions** — Never bare `except:`, always catch specific types
- **async/await for I/O** — All file I/O and network calls should be async
- **No `print()` in library code** — Use logging instead

## Error Handling Patterns

### Library Code (src/docscraper/)

```python
# CORRECT: Specific exception, informative message
try:
    response = await crawler.arun(url=target_url)
except aiohttp.ClientError as e:
    self._logger.error("Failed to scrape %s: %s", target_url, e)
    raise ScrapingError(f"Network error scraping {target_url}") from e

# INCORRECT: Bare except, swallowed error
try:
    response = await crawler.arun(url=target_url)
except:
    pass  # Never do this
```

### API Layer (api/)

```python
# Standard error response format
from fastapi import HTTPException

raise HTTPException(
    status_code=400,
    detail={
        "code": "INVALID_URL",
        "message": "The provided URL is not a valid documentation site.",
        "details": {"url": url, "reason": "No HTML content found"}
    }
)
```

### Standard HTTP Status Codes

| Code | Meaning | When to Use |
|------|---------|-------------|
| 200 | OK | Successful GET, PUT, PATCH |
| 201 | Created | Successful POST that creates a resource |
| 202 | Accepted | Job submitted (async processing) |
| 400 | Bad Request | Validation error (client mistake) |
| 401 | Unauthorized | Missing or invalid API key |
| 403 | Forbidden | Valid key but insufficient permissions |
| 404 | Not Found | Resource doesn't exist |
| 409 | Conflict | Duplicate resource |
| 413 | Payload Too Large | Upload exceeds size limit |
| 429 | Too Many Requests | Rate limit exceeded |
| 500 | Internal Server Error | Server bug (our mistake) |

## Testing Patterns

### Test Structure

```python
import pytest
from docscraper.cleaning.cleaner import PostScraperCleaner


class TestPostScraperCleaner:
    """Tests for PostScraperCleaner."""

    def test_removes_navigation_patterns(self, sample_markdown: str) -> None:
        """Navigation elements are stripped from cleaned output."""
        cleaner = PostScraperCleaner()
        result = cleaner.clean(sample_markdown)
        assert "Skip to content" not in result

    def test_preserves_code_blocks(self, sample_markdown: str) -> None:
        """Code blocks are never modified by cleaning patterns."""
        cleaner = PostScraperCleaner()
        result = cleaner.clean(sample_markdown)
        assert "```python" in result

    @pytest.mark.asyncio
    async def test_async_processing(self, tmp_path: Path) -> None:
        """Async processing completes without errors."""
        ...
```

### What to Test

| Always Test | Sometimes Test | Never Test |
|-------------|---------------|------------|
| Cleaning pattern accuracy | Exact output formatting | crawl4ai internals |
| API request/response schemas | Performance benchmarks | OpenAI API responses |
| Authentication middleware | GUI event handling | Third-party library behavior |
| Job queue state transitions | File encoding edge cases | Python stdlib |
| Error handling paths | Rate limiter timing | |

## API Patterns (Phase 1+)

### Request/Response Format

```python
# Successful response
{
    "data": { ... },
    "meta": {
        "request_id": "req_abc123",
        "timestamp": "2026-03-22T10:30:00Z"
    }
}

# Error response
{
    "error": {
        "code": "VALIDATION_ERROR",
        "message": "Human-readable message",
        "details": { ... }
    },
    "meta": {
        "request_id": "req_abc123"
    }
}

# Paginated response
{
    "data": [ ... ],
    "meta": {
        "request_id": "req_abc123",
        "page": 1,
        "per_page": 20,
        "total": 147
    }
}
```

### Endpoint Naming

| Operation | HTTP Method | Route Pattern | Example |
|-----------|-------------|---------------|---------|
| Submit job | POST | `/api/v1/{resource}` | `POST /api/v1/scrape` |
| List jobs | GET | `/api/v1/{resource}` | `GET /api/v1/jobs` |
| Get one | GET | `/api/v1/{resource}/{id}` | `GET /api/v1/jobs/123` |
| Get result | GET | `/api/v1/{resource}/{id}/result` | `GET /api/v1/jobs/123/result` |
| Cancel | DELETE | `/api/v1/{resource}/{id}` | `DELETE /api/v1/jobs/123` |
