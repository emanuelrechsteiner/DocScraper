## Executive Summary

**Project:** Parsify
**Research Date:** 2026-03-22
**Domains Evaluated:** 11
**Key Decisions:** 7 ADRs

Parsify wraps existing async Python scraping engines in a production REST API. The stack centers on FastAPI (native async, auto-docs), PostgreSQL (relational data), ARQ (lightweight async job queue), and Railway (managed deployment). Key trade-off: simplicity over scale — optimizing for fast time-to-market with a clear migration path if volume demands it.

## Core Technology Stack

### API Framework

| Criterion | Evaluation |
|-----------|-----------|
| **Selected** | FastAPI >=0.115.0 |
| **Alternatives Considered** | Django REST Framework, Flask + Flask-RESTX |
| **Key Reasons** | Native async/await, auto-generated OpenAPI docs, Pydantic validation |
| **Trade-offs** | Smaller ecosystem than Django, no built-in admin panel |
| **Risk Level** | LOW |

**Decision:** ADR-001 (see ARCHITECTURE.md)

**Implementation Pattern:**

```python
from fastapi import FastAPI, Depends, HTTPException
from pydantic import BaseModel, HttpUrl

app = FastAPI(title="Parsify API", version="1.0.0")

class ScrapeRequest(BaseModel):
    url: HttpUrl
    max_depth: int = 3
    max_pages: int = 100
    use_llm: bool = False

@app.post("/api/v1/scrape", status_code=202)
async def submit_scrape(
    request: ScrapeRequest,
    user: User = Depends(get_current_user),
):
    job = await create_job(user_id=user.id, config=request)
    await enqueue_scrape_job(job.id)
    return {"data": {"job_id": job.id, "status": "queued"}}
```

### Job Queue

| Criterion | Evaluation |
|-----------|-----------|
| **Selected** | ARQ >=0.26.0 (Redis-backed) |
| **Alternatives Considered** | Celery, Dramatiq, RQ |
| **Key Reasons** | Async-native (matches crawl4ai), lightweight, Redis-backed |
| **Trade-offs** | Less mature than Celery, smaller community, limited workflow features |
| **Risk Level** | MEDIUM |

**Decision:** ADR-003

**Implementation Pattern:**

```python
from arq import create_pool
from arq.connections import RedisSettings

async def scrape_job(ctx, job_id: str) -> None:
    """ARQ worker function for scraping jobs."""
    job = await get_job(job_id)
    await update_job_status(job_id, "running")
    try:
        scraper = DocumentationScraper(url=job.url, config=job.config)
        result = await scraper.scrape()
        await save_results(job_id, result)
        await update_job_status(job_id, "completed")
    except Exception as e:
        await update_job_status(job_id, "failed", error=str(e))

class WorkerSettings:
    functions = [scrape_job]
    redis_settings = RedisSettings.from_dsn(REDIS_URL)
    max_jobs = 5
    job_timeout = 1800  # 30 minutes
```

### Authentication

| Criterion | Evaluation |
|-----------|-----------|
| **Selected** | API Key (SHA-256 hashed, prefix-based lookup) |
| **Alternatives Considered** | OAuth 2.0, JWT |
| **Key Reasons** | Simplest for developer API, stateless, per-key rate limiting |
| **Trade-offs** | No built-in scopes/permissions, no token expiry |
| **Risk Level** | LOW |

**Decision:** ADR-004

**Implementation Pattern:**

```python
import hashlib
import secrets

def generate_api_key() -> tuple[str, str]:
    """Generate API key and its hash. Returns (full_key, key_hash)."""
    raw_key = secrets.token_urlsafe(32)
    full_key = f"pk_{raw_key}"
    key_hash = hashlib.sha256(full_key.encode()).hexdigest()
    return full_key, key_hash

def verify_api_key(key: str, stored_hash: str) -> bool:
    return hashlib.sha256(key.encode()).hexdigest() == stored_hash
```

## Domain-Specific Research

### Rate Limiting

**Requirements:** Per-API-key rate limiting, different limits per subscription tier, standard 429 responses.

**Approach Selected:** slowapi (built on limits library) + Redis backend

**Implementation Pattern:**

```python
from slowapi import Limiter
from slowapi.util import get_remote_address

def get_api_key(request: Request) -> str:
    return request.headers.get("Authorization", "anonymous")

limiter = Limiter(
    key_func=get_api_key,
    storage_uri=REDIS_URL,
)

@app.post("/api/v1/scrape")
@limiter.limit("10/minute")  # Default, overridden per-tier
async def submit_scrape(request: Request, ...):
    ...
```

**Alternatives Rejected:**
- Custom middleware — More work, less battle-tested
- Nginx rate limiting — Per-IP not per-key, less flexible

### Billing (Stripe)

**Requirements:** Subscription tiers (free/pro/enterprise), usage tracking, self-service checkout.

**Approach Selected:** Stripe Subscriptions with metered billing for overages.

**Implementation Pattern:**

```python
import stripe

# Create checkout session for subscription
session = stripe.checkout.Session.create(
    customer=customer_id,
    mode="subscription",
    line_items=[{"price": price_id, "quantity": 1}],
    success_url=f"{BASE_URL}/billing/success?session_id={{CHECKOUT_SESSION_ID}}",
    cancel_url=f"{BASE_URL}/billing/cancel",
)

# Webhook handler
@app.post("/api/v1/webhooks/stripe")
async def stripe_webhook(request: Request):
    payload = await request.body()
    sig_header = request.headers.get("stripe-signature")
    event = stripe.Webhook.construct_event(payload, sig_header, WEBHOOK_SECRET)

    if event["type"] == "customer.subscription.updated":
        await update_user_tier(event["data"]["object"])
```

### Documentation Site

**Requirements:** Markdown-based, auto-generated API reference from OpenAPI, good search, easy to maintain.

**Approach Selected:** MkDocs with Material theme

**Alternatives Rejected:**
- Sphinx — Powerful but RST-centric, steeper learning curve for markdown docs

- ReadTheDocs — Free hosting but limited customization

### SDK Generation

## Security Considerations

| Area | Risk | Mitigation | Priority |
|------|------|------------|----------|
| API Key Storage | Plaintext key leak | SHA-256 hashing, prefix-only in DB | HIGH |
| SSRF via Scraping | Internal network access | URL validation, block private IPs | HIGH |
